# vault-save — фиксация итогов сессии в mdgraph vault

Путь к скрипту mdgraph.py указан в строке `[mdgraph] …` автозагруженного
контекста в начале сессии (обычно `${CLAUDE_PLUGIN_ROOT}/mdgraph.py`).
Vault — в переменной `$MDGRAPH_VAULT`.

## Шаги

1. Определи, что сделано в сессии: какие файлы, функции, решения затронуты.
2. Обнови затронутые заметки vault: факты, решения, открытые вопросы.
   Пиши результат, а не транскрипт процесса.
3. Новое standalone-знание — новый файл + `[[wikilink]]` из родительской
   заметки (иначе он станет orphan и потеряется). Формат: `kebab-case.md`,
   YAML frontmatter (`tags`, `status`, `updated`), заголовок `#`.
4. Лог сессии: `sessions/YYYY-MM-DD-<slug>.md` (что сделано, что осталось)
   + ссылка из `sessions/index.md`.
5. Гигиена графа: `python3 <скрипт> graph --vault "$MDGRAPH_VAULT"` —
   почисти битые ссылки, разбери orphan-заметки (влить в раздел или удалить,
   если пусто).
6. Устаревшее не удаляй молча — пометь в frontmatter `status: outdated`
   и объясни, чем заменено.

Полные правила ведения vault — в `AGENTS.md` внутри самого vault.

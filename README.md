# mdgraph — долгосрочная память для AI-агентов в виде графа markdown-заметок

Решает проблему потери контекста между сессиями с LLM: вместо перечитывания
вся истории агент в начале работы делает `query index` и получает карту знаний,
затем `query <заметка>` — и читает только релевантные узлы графа, переходя по
ссылкам, а не весь объём.

## Принципы

- **It's just Markdown.** Vault — папка с .md-файлами, `[[wikilinks]]` и YAML
  frontmatter. Никакой БД, индексов и зависимостей: один файл `mdgraph.py`,
  только стандартная библиотека Python 3.9+.
- **Независимость от CLI.** Любой агент, умеющий выполнять команды шелла
  (ZCode, Claude Code, Cline, Cursor), работает с vault одинаково. Вывод —
  текст или `--json`.
- **Совместимость с Obsidian.** Vault открывается в Obsidian как обычная
  папка: граф ссылок, backlink-панель и редактор — бесплатно. Но Obsidian
  не требуется.
- **Человек — владелец.** Заметки читаются и правятся руками; агент —
  такой же участник, только быстрее.

## Установка

Нужен только Python 3.9+, зависимостей нет.

| ОС | Установка Python | Запуск |
|---|---|---|
| Windows | `winget install Python.Python.3.12` | `mdgraph.bat <команда>` |
| macOS | `brew install python` или `xcode-select --install` | `./mdgraph <команда>` |
| Linux | пакетный менеджер дистрибутива (`apt install python3` и т.п.) | `./mdgraph <команда>` |

На macOS/Linux перед первым запуском: `chmod +x mdgraph`. Обёртка сама
находит интерпретатор: `$MDGRAPH_PYTHON` → `python3` → `python` →
Homebrew/pyenv/системные пути; при необходимости можно указать свой явно:
`MDGRAPH_PYTHON=/usr/local/bin/python3.13 ./mdgraph graph`.

Сойдёт и прямой вызов, без обёртки: `python3 mdgraph.py <команда>` —
работает одинаково на всех платформах.

Путь к vault по умолчанию — `./vault`; переопределяется флагом `--vault`
или переменной окружения `MDGRAPH_VAULT`.

## Плагин Claude Code

Опционально: плагин автоматизирует цикл памяти. SessionStart-хук кладёт
карту знаний vault (`query index`) в контекст каждой сессии, Stop-хук
напоминает сохранить итоги, если заметки не обновлялись больше 2 часов,
скилл `vault-save` фиксирует результаты по правилам AGENTS.md.

Требования: Python 3.9+ и `jq` (macOS: `brew install jq`).

Из локального клона репозитория:

    claude plugin marketplace add /путь/к/mdgraph
    claude plugin install mdgraph@mdgraph

С GitHub:

    claude plugin marketplace add <owner>/mdgraph
    claude plugin install mdgraph@mdgraph

Затем укажите абсолютный путь к vault в `~/.claude/settings.json`:

```json
{
  "env": { "MDGRAPH_VAULT": "/абсолютный/путь/к/vault" }
}
```

Если vault ещё нет — создайте: `python3 mdgraph.py init /путь/к/vault`.
Перезапустите Claude Code: в начале каждой сессии в контексте появится
блок `[mdgraph] Карта знаний vault (автозагрузка)`.

Без переменной `MDGRAPH_VAULT` хуки молча пропускают работу — плагин
не мешает проектам без vault.

## Команды

    python mdgraph.py init [ПАПКА]                    # создать скелет vault + AGENTS.md
    python mdgraph.py graph [--vault ПАПКА] [--json]  # узлы, связи, хабы, orphan, битые ссылки
    python mdgraph.py query ЗАМЕТКА [--depth N] [--max-tokens N] [--vault ПАПКА]
    python mdgraph.py find СЛОВО [--vault ПАПКА] [--json]

- `query` — главный рабочий инструмент: заметка + соседи по ссылкам (обход в
  ширину до `--depth`), вывод обрезается по `--max-tokens` (по умолчанию 6000;
  оценка ~3 символа/токен, консервативно для кириллицы). В шапке каждого узла —
  его исходящие (`→`) и входящие (`←`) ссылки.
- `graph` — гигиена: orphan-заметки (ни ссылок, ни бэклинков — потеряются)
  и битые `[[ссылки]]`. С `--json` отдаёт полный граф для скриптов.
- `find` — поиск по имени файла, заголовку, тегам и контенту.
- Ссылки `[[...]]` внутри кода (inline и fenced) игнорируются — это
  документация, не граф. Верхнеуровневые `README.md` и `AGENTS.md` в граф
  не входят.

## Подключение агента

`init` кладёт в vault файл `AGENTS.md` с инструкцией: что читать в начале
сессии, как обновлять заметки после работы, как поддерживать гигиену графа.
Чтобы агент о нём узнал, добавьте в корень своего проекта `AGENTS.md`
(или `CLAUDE.md`) одну строку:

    Работаем с базой знаний в vault/: действуй по инструкции vault/AGENTS.md.

Пример цикла: в начале сессии агент выполняет
`query index --depth 1 --vault vault`, работает, а в конце обновляет
затронутые заметки и проверяет `graph` на orphan и битые ссылки.

## Структура vault (создаётся init)

    vault/
      index.md        карта знаний — точка входа
      projects/       по заметке на проект: цель, состояние, вопросы
      decisions/      ADR: YYYY-MM-DD-<slug>.md — решения и их причины
      sessions/       короткие логи сессий
      inbox/          сырые заметки до разбора
      AGENTS.md       инструкция для агентов
      README.md       шпаргалка для людей

## Чем это отличается от альтернатив

- **Cline Memory Bank** — плоский набор файлов, агент перечитывает много;
  здесь граф: `query --depth 1 --max-tokens` даёт релевантную окрестность
  темы в пределах бюджета.
- **Obsidian + MCP-сервер** — требует запущенный Obsidian и REST-плагин;
  здесь граф живёт в файлах, а CLI — один скрипт на Python.
- **IWE** — зрелее, но свой диалект ссылок и привязка к их CLI; здесь —
  стандартные Obsidian-wikilinks и ноль зависимостей.

## Ограничения

Поиск `find` — по подстроке, не семантический: он находит заметки по точным
словам. Это осознанный выбор (никаких эмбеддингов и внешних сервисов);
наводка в граф через `query` обычно доводит до нужной темы по ссылкам.
